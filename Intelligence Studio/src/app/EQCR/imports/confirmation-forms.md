Text header:

“This confirmation must be completed for each engagement in which you are assigned as EQCR.”

Fields / sections:

EQCR Name (text input, default = current user)
Legal Entity Name

If the engagement includes multiple legal entities reported as one, include the overall engagement name (text input)


Year of Appointment as EQCR on the engagement (date input)
EQCR Appointment Criteria A (static text + 2 checkboxes)

Checkbox: “I have read Criteria A and comply.”
Checkbox: “I cannot comply with one or more items in Criteria A.”


If non-compliant with Criteria A, explain why (text input)
EQCR Appointment Criteria B (static text + 2 checkboxes)

Checkbox: “I have read Criteria B and comply.”
Checkbox: “I cannot comply with one or more items in Criteria B.”


If non-compliant with Criteria B, explain why (text input)
EQCR Performance Requirements (static text + 2 checkboxes)

Checkbox: “I have read section 10.4.2 (GQ&RMM) and will perform the required procedures.”
Checkbox: “I cannot comply with the performance requirements in section 10.4.2 (GQ&RMM).”


If non-compliant with Performance Requirements, explain why (text input)
EQCR Documentation Requirements (static text + 2 checkboxes)


Checkbox: “I have read section 10.4.2 (GQ&RMM) and will comply.”
Checkbox: “I cannot comply with the documentation requirements in section 10.4.2 (GQ&RMM).”


EQCR Assistant (static text + 2 checkboxes)


Checkbox: “I require an EQCR Assistant and understand my responsibility to direct, supervise, and review their work.”
Checkbox: “I do not require an EQCR Assistant.”

End with Send button that submits and emails the completed form.
